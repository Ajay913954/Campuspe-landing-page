# 🎓 CampusPe — Landing Page

A pixel-perfect, fully responsive, and interactive landing page for **CampusPe**, built with **Next.js** and **Vanilla CSS** matching the official Figma design.

---

## 🔗 Links

- **🌐 Live Demo:** [https://campuspe-landing-page-sage.vercel.app/](https://campuspe-landing-page-sage.vercel.app/)
- **💻 GitHub Repo:** [https://github.com/Ajay913954/Campuspe-landing-page](https://github.com/Ajay913954/Campuspe-landing-page)

---

## ✨ Features

- **🎯 Pixel-Perfect Design**: 1:1 match with the Figma artboard using a unified 1240px container layout.
- **🚀 3-Column Hero Section**: WhatsApp notifications, AI Assistant pill, Resume Builder card, 3 interactive role selection cards, and platform metrics.
- **🔄 Infinite Partners Marquee**: Smooth, continuous right-to-left scrolling logo carousel (DPIIT, Startup Karnataka, GINSERV, VTU, TalentSpotify, Radiant Info).
- **💼 Opportunity Feed**: Interactive job & internship discovery feed with real-time category filtering.
- **📄 AI Resume Scanner**: Interactive resume upload simulation with sample resume chips and ATS feedback.
- **🏛️ Colleges & Employers Workflows**: 4-card structured workflows with status tags and verified badges.
- **📱 5-Phone App Showcase**: Clean showcase displaying all 5 mobile app interfaces simultaneously.
- **📲 3D Download Section**: Isometric dual-phone visual with Google Play & App Store buttons.
- **💬 Glass Support & CTA**: "Still have questions?" glassmorphic card and "Ready for what's next?" quick action bar.
- **🧭 5-Column Footer**: Complete ecosystem footer with contact pills, policy links, and social icons.
- **📱 100% Responsive**: Zero horizontal scroll across all screens (Desktop, Tablet, and Mobile / iPhone 13 mini).

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15+ (App Router)
- **Library**: React 19
- **Styling**: Vanilla CSS (Custom Design System, Flexbox, CSS Grid)
- **Deployment**: Vercel

## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Ajay913954/Campuspe-landing-page.git
cd Campuspe-landing-page
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm start
```
