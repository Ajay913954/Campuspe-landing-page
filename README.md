# Campuspe-landing-page

A pixel-accurate, fully responsive, and interactive landing page for **CampusPe**, built using Next.js, React, HTML, CSS, and modern web best practices directly from the official Figma design.

---

## 🚀 Live Demo & Repository
- **GitHub Repository**: [https://github.com/Ajay913954/Campuspe-landing-page](https://github.com/Ajay913954/Campuspe-landing-page)

---

## ✨ Features

- **Pixel-Accurate Figma Design**: Replicates the authentic layout, color palette, gradients, and typography from the Figma artboard.
- **Continuous Partner Marquee**: Smooth right-to-left infinite scrolling logo marquee featuring GINSERV, Startup Karnataka, VTU / Karnataka Government emblem, TalentSpotify, Radiant Info, and DPIIT #startupindia with pause-on-hover.
- **Interactive Role Cards**: Role selection for Colleges, Students seeking jobs, and Employers with active selections, badges, and micro-interactions.
- **Opportunity Discovery & Feed**: Filterable opportunities feed card (*All, Colleges, Jobs, Internships, Freelance, Part-time*) with curated cards and handwritten annotations.
- **Resume Scanner & Match Engine**: Interactive drag-and-drop / click-to-upload resume simulator with instant matching status and metrics.
- **College & Employer Workflows**: 4-step structured cards highlighting verified profiles, direct enrollment, instant setup, and time-to-hire reduction.
- **App Interface Showcase**: 5 fanned 3D iPhone interfaces with active pagination indicators.
- **3D Download Section**: Isometric 3D phone presentation with Google Play and Apple App Store buttons.
- **Glass Support Card & Quick CTAs**: Frosted glassmorphism "Still have questions?" card with Contact Support and Schedule a Call actions, plus the "Ready for what's next?" banner.
- **Comprehensive Light Footer**: 5 structured columns, policy callout box, direct contact pills, status indicator, social links, and radiant ambient bottom glow.
- **100% Responsive**: Tailored viewport experiences for mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Library**: [React](https://react.dev/)
- **Styling**: Vanilla CSS (CSS Variables, Flexbox, CSS Grid, Glassmorphism, CSS Animations)
- **Assets**: Optimized PNG & SVG assets

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Ajay913954/Campuspe-landing-page.git
cd Campuspe-landing-page
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for production
```bash
npm run build
npm run start
```
